Política de Privacidade — Vader

Última atualização: 16 de novembro de 2026.

O Vader é um assistente pessoal de uso privado, operado por Gustavo Pizani exclusivamente para as suas próprias contas Google. Não é oferecido a terceiros.

Dados acessados

Com autorização do titular, o Vader acessa Gmail, Google Agenda e serviços relacionados das contas do próprio Gustavo Pizani, para ler, resumir e organizar e-mails e compromissos a pedido dele.

Uso e compartilhamento

Os dados são usados apenas para atender aos pedidos do titular. Não são vendidos, compartilhados com terceiros para publicidade nem usados para treinar modelos. O uso de dados recebidos das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Armazenamento

Os tokens de acesso ficam armazenados em servidor privado do titular. O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.
